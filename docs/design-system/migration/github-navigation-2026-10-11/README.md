# GitHub navigation

Desktop replaces the Download navigation item with the official GitHub mark and label; Get Ovelle still downloads the app. Mobile retains Download and places GitHub in the dropdown, with “View source on GitHub” and the existing external-link arrow. Repository: https://github.com/Atripix-Design/ovelle.

References: [shadcn/ui](https://ui.shadcn.com/) uses a compact GitHub header link; [Vite](https://vite.dev/) supplies an explicit GitHub destination. Ovelle keeps its own Inter typography, 44px header targets, 12px control radius and shared Solid/Liquid Glass surfaces. No star count is shown. The mark comes from [GitHub’s Octicons](https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg), imported without path changes into Figma, then exported as exact 16×16 Light and Dark SVGs.

Figma family: [Ovelle / GitHub link](https://www.figma.com/design/6jsC9SLa0LYsZKjJXxlY1K?node-id=264-8424) on 05 Components. Forty variants cover Compact/Menu × Light/Dark × Solid/Liquid Glass × Default/Hover/Pressed/Focused/Disabled. All surfaces are linked public Ovelle / Navigation item instances. The public navigation wrapper now lets its nested surface fill its bounds; its original 144×44 geometry is preserved. Desktop and mobile sources compose linked GitHub link instances. Current/selected, loading, success/error and open do not apply to an external repository link. Pressed shares the existing navigation hover surface.

React export: `GitHubLink`, `GitHubLinkProps`, `ovelleRepositoryUrl`. Navigation’s `githubHref` defaults to this repository; `null` opts out. Keyboard arrow/Home/End navigation includes the mobile link; Escape returns focus to Menu. Selecting GitHub closes the dropdown and opens a new tab with `noopener noreferrer`. Materials, continuous frost, reduced transparency and theme come from the existing provider and control. No new motion or data-dependent region is introduced.

Evidence: source contexts and Figma reference renders are stored here, alongside website and desktop captures, real Home header/menu captures, and `audit.json`. `scripts/check-github-navigation.mjs` checks both consumers, 390/320px mobile widths, external-link semantics, keyboard focus/dismissal, inert skeleton content and native icon geometry across two themes, two materials and three frost levels. Existing dynamic-loading and Figma-fidelity scripts passed in both consumers. The publish patch was isolated from concurrent homepage work for build, type, lint and unit verification.

Visual inspection: rendered header and dropdown inspected beside Figma. CSS backdrop blur and Figma’s native glass renderer differ optically; the shared control geometry, typography and exact mark slots match the source. Existing content/navigation out-of-scope discrepancies were not changed. Figma and React remain independently maintained.

Electron’s main process sends the exact Ovelle repository URL to the system browser and still denies all popup windows. The real transpiled main module was checked with mocked Electron APIs: the repository invoked `shell.openExternal`; unrelated, script and lookalike-host destinations did not. Isolated publish verification passed all 13 UI tests, workspace type checks and lint. The working workspace’s full type and lint checks also passed after concurrent homepage changes settled.
