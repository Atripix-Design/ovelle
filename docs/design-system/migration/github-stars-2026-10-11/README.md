# GitHub star count

The desktop header and mobile dropdown show the repository’s public GitHub star count. A 40×24 badge sits beside the existing GitHub label; the compact control is 152×44 with counts enabled. The badge uses Ovelle’s selected surface, default border, 999px radius and Inter Medium 12/18 typography. The official mark and existing navigation surfaces remain unchanged and linked.

Figma: `Ovelle / GitHub link` (`264:8424`) keeps all 40 theme/material/layout/interaction variants, now with `Show stars#283:82` and `Star count#283:123`. Native review `283:12000` shows zero, a large count, unavailable data and dark glass using linked instances. Desktop and mobile navigation compositions enable the count. `context.txt` contains the full source context for loaded instance `283:12001`; source captures include the count review, glass header and dropdown. Loading uses the established dynamic mask on the real count region, without a new Skeleton sheet.

React maps these properties to `starCount` and `starsLoading`; the parent navigations forward `githubStarCount` and `githubStarsLoading`. Undefined omits the badge, null is unavailable, zero displays 0, and larger values use compact English notation with two significant digits to fit the reserved width. A tooltip and accessible text expose the full count. Only the count is inert while loading, so the repository destination stays usable. Badge DOM is retained from loading to loaded; its reserved size prevents layout movement. Existing material, frost, transparency and reduced-motion behavior is inherited.

The application hook reads [GitHub’s repository REST API](https://docs.github.com/en/rest/repos/repos#get-a-repository), validates `stargazers_count` as a nonnegative safe integer, shares in-flight requests through StrictMode and caches successful counts in optional local storage for 15 minutes. Fresh cached values avoid a request on revisits; expired entries fetch again. Requests stop after five seconds. Failures, rate limiting and invalid data show — rather than a fabricated zero. Repository: https://github.com/Atripix-Design/ovelle. No secret or authentication credential is present in the client.

`scripts/check-github-stars.mjs` verifies both website and desktop renderer: pending/loaded dimensions, retained badge node, one StrictMode request, cached reload, zero, large count, service failure, invalid response, 990k badge containment, mobile 390/320 geometry and keyboard dismissal. Captures and audit are stored here. Existing Figma fidelity and dynamic-loading checks run in both consumers. Native glass and CSS backdrop rendering remain optically different; source geometry, count typography and asset slots are compared directly. The badge is a solid tint within the existing glass navigation surface.
